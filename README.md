## 🏗️ Products I Created

Beyond infrastructure, I design and build my own products end-to-end — from idea to architecture to production.

### 💇‍♀️ [VamoMarca](https://vamomarca.com.br)

![VamoMarca](https://img.shields.io/badge/VamoMarca-Online_Scheduling-FF4D8D?style=for-the-badge)
![Role](https://img.shields.io/badge/Role-Founder%20%26%20Creator-black?style=for-the-badge)

Online booking platform for beauty and wellness professionals — hair, lashes, brows, nails, skincare, barbershops and podology. Every professional gets a personal booking link, a per-professional agenda, client records, cash/commission control and a branded page, replacing scheduling scattered across paper, WhatsApp and memory.

### 🖨️ [FormaOS](https://formaos.com.br)

![FormaOS](https://img.shields.io/badge/FormaOS-3D_Printing_ERP-F7941D?style=for-the-badge)
![Role](https://img.shields.io/badge/Role-Founder%20%26%20Creator-black?style=for-the-badge)

Management system (ERP) for 3D printing workshops and print farms. Calculates the real cost of every print — filament, purge, energy, machine-hour, finishing — and shows the margin before the quote goes out, ending guesswork pricing and production that depends on one person's memory.

### 🛡️ [Breachscope](https://breachscope.com.br)

![Breachscope](https://img.shields.io/badge/Breachscope-Continuous_Security-E63946?style=for-the-badge)
![Role](https://img.shields.io/badge/Role-Founder%20%26%20Creator-black?style=for-the-badge)

Continuous security platform for code, web applications and networks — SAST, DAST, SCA, network and architecture analysis orchestrated in a single dashboard, with no agent installed on the client's infrastructure. Built for DevSecOps/CI-CD teams, compliance (LGPD, PCI-DSS) and agencies that need ongoing coverage instead of a once-a-year pentest.
